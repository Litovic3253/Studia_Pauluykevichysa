Студия Паулюкевичуса — учёт заказов 3D-печати
==============================================

УСТАНОВКА
1. Распакуйте архив в любую папку, например «Документы\Студия Паулюкевичуса».
   Не запускайте программу прямо из архива — иначе данные не сохранятся.
2. Запустите «Студия Паулюкевичуса.exe».
   Если Windows покажет синее окно «Система Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае». Это обычное
   предупреждение для программ без платной цифровой подписи.
3. Первый запуск может занять 10–20 секунд, дальше быстрее.

ГДЕ ХРАНЯТСЯ ДАННЫЕ
Всё хранится рядом с программой, в той же папке:
  orders.db       — заказы, клиенты, цены
  files_storage\  — прикреплённые к заказам файлы
Интернет не нужен. В сеть данные уходят, только если вы сами включите
синхронизацию с GitHub или Google Таблицами (см. ниже).

ДВА КОМПЬЮТЕРА: СИНХРОНИЗАЦИЯ ЧЕРЕЗ GITHUB (необязательно)
Данные можно держать в своём ПРИВАТНОМ репозитории GitHub и не переносить
вручную. Настройка — один раз на каждом компьютере:
1. На github.com создайте пустой приватный репозиторий, например Studia_data.
2. Создайте токен: Settings → Developer settings → Fine-grained tokens,
   доступ только к этому репозиторию, право Contents: Read and write.
3. В программе внизу меню: «Настройка GitHub» → вставьте название
   репозитория и токен → «Сохранить».
Дальше:
  • после каждого изменения данные сами выгружаются в GitHub;
  • «Выгрузить в GitHub» — отправить вручную;
  • «Скачать из GitHub» — забрать свежие данные на этом компьютере.
    Прежняя база сохраняется рядом как orders.backup-<дата>.db.
При запуске программа сама сообщит, если в GitHub есть данные новее.
Работайте по очереди: скачали — поработали — данные выгрузились. Если
изменения появились сразу на двух компьютерах, программа спросит, какую
версию оставить (объединить их нельзя).
Токен хранится в файле .env рядом с программой — никому его не передавайте.

ПЕРЕНОС НА ДРУГОЙ КОМПЬЮТЕР БЕЗ GITHUB / РЕЗЕРВНАЯ КОПИЯ
Закройте программу и скопируйте всю папку целиком (exe + orders.db +
files_storage). На новом компьютере просто запустите exe из этой папки.

ЭКСПОРТ
Кнопка со стрелкой вниз слева вверху — сохранить все данные в Excel.

GOOGLE ТАБЛИЦЫ (необязательно)
Можно включить автоматическую копию данных в свою Google Таблицу:
положите рядом с exe файл .env с двумя строками
  GOOGLE_SHEET_ID=...
  GOOGLE_SERVICE_ACCOUNT_FILE=google-service-account.json
и сам JSON-ключ. Подробная настройка — в README проекта.
