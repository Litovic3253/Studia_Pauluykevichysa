Mochi Desktop — учёт заказов 3D-печати
======================================

УСТАНОВКА
1. Распакуйте архив в любую папку, например «Документы\Mochi Desktop».
   Не запускайте программу прямо из архива — иначе данные не сохранятся.
2. Запустите «Mochi Desktop.exe».
   Если Windows покажет синее окно «Система Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае». Это обычное
   предупреждение для программ без платной цифровой подписи.
3. Первый запуск может занять 10–20 секунд, дальше быстрее.

ГДЕ ХРАНЯТСЯ ДАННЫЕ
Всё хранится рядом с программой, в той же папке:
  orders.db       — заказы, клиенты, цены
  files_storage\  — прикреплённые к заказам файлы
Интернет не нужен. Никуда в сеть данные не отправляются.

ПЕРЕНОС НА ДРУГОЙ КОМПЬЮТЕР / РЕЗЕРВНАЯ КОПИЯ
Закройте программу и скопируйте всю папку целиком (exe + orders.db +
files_storage). На новом компьютере просто запустите exe из этой папки.

ЭКСПОРТ
Кнопка со стрелкой вниз слева вверху — сохранить все данные в Excel.

GOOGLE ТАБЛИЦЫ (необязательно)
Можно включить автоматическую копию данных в свою Google Таблицу:
положите рядом с exe файл .env с двумя строками
  GOOGLE_SHEET_ID=...
  GOOGLE_SERVICE_ACCOUNT_FILE=google-service-account.json
и сам JSON-ключ. Подробная настройка — в README проекта.
