# Mochi — бот для заказов 3D-печати

Telegram: [@MochiRNDbot](https://t.me/MochiRNDbot)

## Запуск

Дважды кликнуть `start.bat` (при первом запуске сам создаст `.venv` и поставит зависимости).
Бот работает, пока открыто окно.

Вручную:

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python bot.py
```

## Настройка (`.env`)

- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_IDS` — ваш Telegram ID (через запятую, если несколько). Если пусто — владельцем становится первый, кто нажал /start; остальным бот отвечает «приватный бот».

## Что умеет

- **Новый заказ** — пошагово: клиент, контакт, описание, файл модели/фото, материал, цвет, вес, время, количество, срок. Цена считается автоматически, можно поставить свою.
- **Заказы** — фильтры (активные / неоплаченные / завершённые / все), карточка заказа: смена статуса, оплата, цена, срок, заметка, отправка файла, удаление.
- **Калькулятор** — быстрая оценка стоимости.
- **Статистика** — выручка, прибыль, долги, расход материала.
- **Напоминания** — каждое утро (с 9:00) сводка по заказам со сроком сегодня/завтра/просроченным.

## Формула цены

```
себестоимость = вес × кол-во × цена_материала/1000 + часы × кол-во × цена_часа
цена = max(мин_цена, себестоимость × наценка), округление до 10
```

Тарифы меняются командами `/setprice PLA 1500`, `/sethour 30`, `/setmarkup 2`, `/setmin 300`, `/delmaterial TPU`.

Данные хранятся в `orders.db` (SQLite) — его стоит периодически копировать.
